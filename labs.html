Open-source numerical methods

Libraries for quantitative finance,
built from first principles.

Hand-written numerical methods in C++ and Python. No wrappers around QuantLib, no abstractions hiding the maths. Each library is documented, tested, and used by the demos on the Streamlit Projects page.

01

Foundations

Building-block algorithms — matrix, optimisation, stochastic
numerics-cpp C++ in progress

Hand-rolled linear algebra and root-finding. LU decomposition, Cholesky, QR, Newton-Raphson, conjugate gradient. Header-only where feasible, benchmarked against Eigen.

C++20 CMake Catch2
github docs benchmarks 
// Solve Ax = b via LU with partial pivoting
#include "numerics/lu.hpp"

auto [L, U, P] = numerics::lu_decompose(A);
auto x        = numerics::lu_solve(L, U, P, b);

// ‖Ax − b‖ ≈ 1e-15
stochastic-py Python experimental

Monte Carlo engines and path simulators. GBM, OU, Heston, jump-diffusion. Antithetic and control-variate variance reduction. Composable design via a unified Process protocol.

Python 3.11+ NumPy pytest
github docs pypi 
from stochastic import Heston, simulate

process = Heston(s0=100, v0=0.04, kappa=2.0,
                  theta=0.04, xi=0.3, rho=-0.7)

paths = simulate(process, t=1.0, n_steps=252,
                 n_paths=10_000, antithetic=True)
02

Pricing

Analytic, lattice, and transform methods for derivatives
pricing-cpp C++ stable

European and American options via Black-Scholes, binomial trees, finite difference, and the Carr-Madan FFT-COS method. Analytical Greeks where available, finite-difference fallbacks otherwise.

C++20 CMake Header-only
github docs examples 
#include "pricing/black_scholes.hpp"

bs::Option call{100, 100, 1.0, 0.05, 0.20, bs::Call};

double price = bs::price(call);   // 10.4506
auto   g     = bs::greeks(call);  // Δ, Γ, ν, Θ, ρ
vol-models-py Python in progress

Volatility surface modelling and calibration. Dupire local vol, SABR, SVI, and Heston. Carr-Madan FFT-COS pricer included for fast characteristic-function calibration to market quotes.

Python 3.11+ SciPy NumPy
github docs demo 
from volmodels import Heston, calibrate

market_quotes = load_chain("SPX", expiry="2026-06")

result = calibrate(Heston, market_quotes,
                   method="fft-cos", max_iter=200)

print(result.params)  # κ, θ, ξ, ρ, v₀
