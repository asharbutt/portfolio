Options pricing under COS method

Recall the Feynman-Kac representation to the BS PDE is given by:

$$V(t,x) = e^{-rT}E^{Q}[V(T,y)] = e^{-rT}\int _{-\infty} ^{\infty} V(T,y)f_{X}(T,y;t,x)dy$$

Where f(T,y;t,x) is the transition density from state x to state y for the underlying process. Given the density will decay rapidly to zero when $|y| \to \infty$, we can truncate the intergral interval to [a,b]:

$$V(t,x) = e^{-rT}\int _{a} ^{b} V(T,y)f_{X}(y)dy$$

We may not know what the underlying density is, so we can use the COS approximation to estimate the density function such that:

$$\hat {f} _{X}(y) =\sum _{k=0} ^{N-1} \bar{A}_{k} cos(k \pi \frac{y-a}{b-a})$$

$$\bar{A} _{k} = \frac{2}{b-a} \int _{a} ^{b} \hat {f} _{X}(y) cos(k\pi \frac{y-a}{b-a})dy$$

We can then write the value of the option using the COS expansion for the density:

$$V(t,x) = e^{-rT} \int _{a} ^{b} V(T,y) \sum _{k=0} ^{N-1} \bar{A}_{k} cos(k\pi \frac{y-a}{b-a})$$

Using Leibnitz theorem of exchanging integral orders, which can be applied to exchanging sums and integrals, we write a new function defined as:

$$H(x) = \frac{2}{b-a}\int _{a} ^{b} V(T,y)cos(k\pi \frac{y-a}{b-a})$$

We can substitute this into our options formula and find:

$$V(t,x) = e^{-rT} \frac{b-a}{2}\sum _{k=0} ^{N-1} H_{k} \bar{A}_{k} $$

Using the approximation $\bar{F}_{k}$for $\bar{A}_{k}$ from our previous page, we get the following:

$$V(t,x) = e^{-rT}\sum _{k=0} ^{N-1}H_{k}(x) Re{\phi (\frac{k\pi}{b-a}) e^{-i \frac{k\pi a}{b-a}}}$$

This is our options pricing formula using the COS method. The function $H_{k}(x)$ are the payoff coefficients for V(T,y), and have to be recovered. Their coefficients are available for vanilla and digital options, and solutions are available for other payoffs.

For a call option, we can write the Payoff coefficient as:

$$H_{k} ^{Call} = \frac{2}{b-a} \int _{0} ^{b} K(e^{y} - 1)cos(k\pi \frac{y-a}{b-a})$$

If we are to look at the strike in Log coordinates, such that $y(t) = \log \frac{S}{K}$, then the payoff makes sense, as $\pm K(e^{ln(\frac{S}{K})} - 1) = \pm K(\frac{S}{K}-1)$, which boils down to the Call/Put payoff depending on the sign.

This then becomes: $\frac{2}{b-a} K(\chi _{k}(0,b) - \psi _{k}(0,b))$, where $\chi$ and $\psi$ are given by the following:

$$\chi _{k}(c,d) = \frac{1}{1+ (\frac{k\pi}{b-a})^{2}}[cos(k\pi \frac{d-a}{b-a})e^{d} - cos(k\pi \frac{c-a}{b-a})e^{c} + \frac{k\pi}{b-a}sin(k\pi \frac{d-a}{b-a})e^{d} - \frac{k\pi}{b-a}sin(k\pi \frac{c-a}{b-a})e^{c}]$$

$$\psi _{k}(c,d) = \begin{cases} [sin(k\pi \frac{d-a}{b-a}) - sin(k\pi \frac{c-a}{b-a})]\frac{b-a}{k\pi} &\text{if } k \ne 0\\ (d-c) &\text{if } k = 0 \end{cases}$$

The put option can then be written as: $\frac{2}{b-a} -K(\chi _{k}(a,0) - \psi _{k}(a,0))$

The Greeks

Greeks can be computed quite fast. Recall the Delta formula as: $\Delta = \frac{\partial V}{\partial S}$. Given our COS expansion is given in terms of log coordinates, we can use the chain rule to evaluate this: $\Delta = \frac{\partial V}{\partial x} = \frac{\partial V}{partial x} \frac{\partial x}{\partial S}$. Given x = ln(S), then $\Delta = \frac{1}{S}\ \frac{\partial V}{\partial x}$. The derivative can be calculated by taking the derivative of our COS expansion w.r.t x.

This gives us:

$$ \Delta = \frac{1}{S}e^{-rT}\sum _{k=0} ^{N-1}H_{k} - \frac{i\pi k}{b-a}Re(\phi (\frac{k\pi}{b-a})e^{-i \frac{k\pi a}{b-a})} $$
