Options pricing under COS method

Recall the Feynman-Kac representation to the BS PDE is given by:

$$V(t,x) = e^{-rT}E^{Q}[V(T,y)] = e^{-rT}\int _{-\infty} ^{\infty} V(T,y)f_{X}(T,y;t,x)dy$$

Where f(T,y;t,x) is the transition density from state x to state y for the underlying process. Given the density will decay rapidly to zero when $|y| \to \infty$, we can truncate the intergral interval to [a,b]:

$$V(t,x) = e^{-rT}\int _{a} ^{b} V(T,y)f_{X}(y)dy$$

We may not know what the underlying density is, so we can use the COS approximation to estimate the density function such that:

$$\hat {f} _{X}(y) =\sum _{k=0} ^{N-1} \bar{A}_{k} cos(k \pi \frac{y-a}{b-a})$$

$$\bar{A} _{k} = \frac{2}{b-a} \int _{a} ^{b} \hat {f} _{X}(y) cos(k\pi \frac{y-a}{b-a})dy$$

We can then write the value of the option using the COS expansion for the density:

$$V(t,x) = e^{-rT} \int _{a} ^{b} V(T,y) \sum _{k=0} ^{N-1} \bar{A}_{k} cos(k\pi \frac{y-a}{b-a})$$
