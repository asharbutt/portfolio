Characteristic Function

Like the moment generating function, the characteristic function is a function which fully defines the distribution of a variable, and can be used to evaluate all moments of a random variable. Unlike a moment generating function, the characteristic function always exists. We can define the CF as the Fourier transformation of the PDF:

$$\phi _{X} (u) = \int _{-\infty}^{\infty} e^{iux}f_{X}(x)dx = E[e^{iuX}]$$

Given the imaginary bit, the CF always exists. The above is a relation, meaning we can write the characteristic function as the Fourier transform, however, we do not need to have the PDF to derive the CF. We can use the Fourier inversion method to retrieve the PDF once we have the CF:

$$f_{X}(y) = \frac{1}{2\pi} \int _{-\infty}^{\infty} e^{-iuy}\phi _{X} (u)du$$

The CF allows us to calculate the kth moment via the following differential:

$$E[X^{k}] = \frac{1}{i^{k}} \frac{d}{du^{k}} \phi _{X} (u) \Big|_{u=0}$$

Normal Random Variable CF

We can find the characteristic function of the Normal Random Variable using the standard normal variable. Let X be some variable s.t. $X \sim N(\mu , \sigma ^{2})$. If we define X in terms of a Standard normal random variable, then $X = \mu + \sigma Z$, where $Z \sim N(0 , 1)$. Therefore:

$$E[e^{uiX}] = E[e^{iu(\mu + \sigma Z)}] = e^{iu \mu}E[e^{iu\sigma}Z]$$

We know the MFG for a standard normal variable can be given by: $E[e^{tX}]=e^{\frac{1}{2}t^{2}}$, so if we make the substitution: $t = iu\sigma$, then:

$$ e^{iu \mu}E[e^{iu\sigma}Z] = e^{iu \mu} e^{\frac{1}{2}i^{2} u^{2}\sigma ^{2}}=e^{iu \mu - \frac{1}{2}u^{2} \sigma ^{2}} $$

We can do a quick sanity check by evaluating one of the moments, such as the second moment. We do this by taking the second derivative such that:

$$E[X^{2}]=\frac{1}{i^{2}} \frac{d}{du^{2}} \phi _{X} (u) \Big|_{u=0}$$

$$E[X^{2}]= \frac{1}{-1} [\frac{d}{du} (i \mu - u\sigma ^{2})(e^{iu \mu - \frac{1}{2}u^{2} \sigma ^{2}}) ]\Big|_{u=0}$$

$$E[X^{2}]= \frac{1}{-1} [(-\sigma ^{2})(e^{iu \mu - \frac{1}{2}u^{2} \sigma ^{2}}) + (i \mu - u\sigma ^{2})^{2} e^{iu \mu - \frac{1}{2}u^{2} \sigma ^{2}}) ]\Big|_{u=0}$$

$$E[X^{2}]= \frac{1}{-1} [(-\sigma ^{2})(e^{iu \mu - \frac{1}{2}u^{2} \sigma ^{2}}) + (-\mu ^{2} + u^{2}\sigma ^{4} - 2i\mu u \sigma^{2)} e^{iu \mu - \frac{1}{2}u^{2} \sigma ^{2}}) ]\Big|_{u=0}$$

$$E[X^{2}] = \mu ^{2} + \sigma ^{2} = Var(X) = E[X^{2}]-E[X]^{2}$$

The Fourier Cosine expansion

Proof of the Fourier cosine expansion can be found online or in books like Grzelak 2020, however, we find the following COS expansion of the density function:

$$ \hat{f}_{X}(y) = \sum _{k=0} ^{N-1} \bar{F} _{k} cos(k \pi \frac{y-a}{b-a})$$

$$\bar{F} _{k} = \frac{2}{b-a}Re(\phi _{X}(\frac{k\pi}{b-a}) e^{-i\frac{ka\pi}{b-a}})$$

The first term of this sum has to be weighted by a half. We show this in the following python code: 

import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

def cos_density(char_func, integration_low_bound, integration_upper_bound, summation_count):
    i = complex(0.0, 1.0)
    a = integration_low_bound
    b = integration_upper_bound
    k = np.arange(0, summation_count)
    u = (k * np.pi) / (b - a)
    F_k = 2 / (b-a) * np.real(char_func(u) * np.exp(-i * u * a))
    F_k[0] *= 0.5
    f_x = lambda y: np.sum(F_k * np.cos(k * np.pi * (y - a) / (b - a)))
    return f_x

if __name__ == "__main__":
    i = complex(0.0, 1.0)
    a = -15
    b = 15
    N = [10, 15, 20]
    mu = 0
    sigma = 1
    normal_charFunc = lambda x: np.exp(i*x*mu - 0.5 * x * x * sigma * sigma)
    y = np.linspace(-10, 10, 1000)

    plt.figure(1)
    plt.grid()
    plt.xlabel("x")

    for index, n in enumerate(N):
        f_y = cos_density(normal_charFunc, a, b, n)
        density_value = [f_y(x) for x in y]
        plt.plot(y, density_value, label=f"N={n}")

    actual = [norm.pdf(x, mu, sigma) for x in y]
    plt.plot(y, actual, label="Actual Density")
    plt.legend()
    plt.show()

Lognormal Density

We can also use this method to estimate the lognormal density. A lognormal variable Y is such that: $Ln(Y) = X$, where X is some normal variable. We can also rewrite this as: $Y=e^{\mu + \sigma Z}$, where Z is a standard normal random variable. We can estimate the density of the lognormal variable via the following:

$$\begin{cases} CDF = P[Y \leq y] = P[X \leq Ln(y)] = F_{X} (ln(y)) \\ PDF = \frac{dF_{X} (ln(y))}{dx} = \frac{1}{y}f_{X}(ln(y)) \end{cases}$$

This means we can use our COS estimator for the normal density function and extend it to the lognormal density. We use the adjustment to the above main function:
