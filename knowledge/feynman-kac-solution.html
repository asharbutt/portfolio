The Feynman-Kac Theorem

The Feynman-Kac theorem provides a a probabilistic expectation as a solution to the backward PDE related to the Ito diffusion process:

$$dX = \mu (X,t) dt + \sigma dW^{Q}$$

and its related PDE:

$$\frac{\partial u}{\partial t} + \mu (X,t) \frac{\partial u}{\partial x} + \frac{1}{2} \sigma (X,t) \frac{\partial^{2} u}{\partial x^{2}}$$

with a final condition $$u(X_{T}, T) = H(S,T)$$ Then the Feynman-Kac theorem states that the solution to this PDE can be provided by the expectation:

$$\frac{u(X,t)}{M(t)} = E^{P}[\frac{H(X,T)}{M(T)}| \mathbb{F}_{t}]$$

Where M(T) is the numeraire under the Q measure, in this case the bank account. We can then evaluate this expectation by splitting up the payoff, for example, for a call option:

$$E^{Q}[H(X,T)P(0,T)| \mathbb{F}_{t}] => P(0,T) E^{P}[max(S-K,0)| \mathbb{F}_{t}]$$

This expectation is under the same measure as the original diffusion process, in this case the risk-neutral measure. Given the numeraire is the bank account, we know that $$M(T) = e^{rT}$$, and so $$\frac{M(t)}{M(T)} = e^{-r(T-t)} = P(T,t)$$ or P(0,T) We can use indicator functions to get rid of the maximum operator:

$$P(0,T) E^{P}[max(S-K,0)| \mathbb{F}_{t}] => P(0,T) (E^{P}[S1_{S \geq K}| \mathbb{F}_{t}] - E^{P}[K1_{S \geq K}| \mathbb{F}_{t}])$$

Even though S is lognormally distributed, through a change of variable in the derivation, we change to a standard normal distribution, and the closed form solution is then provided:

$$V(t, S_{0} = S \ N(d_{1}) - \ K \ e^{-rT} \ N(d_{2})$$

where $$d_{1} = \frac{ln(\frac{S_{0}}{K} + (r-q-\frac{1}{2} \ \sigma^{2})T}{\sigma \sqrt{T}}$$ and $$d_{2} = d_{1} - \sigma \sqrt{T}$$

Digital Options

We can evaluate digital options using the Feynman-Kac theorem. For the same asset and PDE, the terminal condition, or payoff, can be written as: $$H(X,T) = max(S,0)$$ for an asset-or-nothing option, and $$H(X,T) = max(K,0)$$ for a cash-or-nothing option. Then, the option expectation for an asset-or-nothing can be written as:

$$V(X,t) = P(0,T) E^{P}[max(S) | \mathbb{F}_{t}] = P(0,T) E^{P}[S1_{S \geq K} | \mathbb{F}_{t}]$$

Thus the closed form solution for an asset-or-nothing call can be written as $$S_{0}N(d_{1})$$, and a cash-or-nothing call can similarly be written as $$Ke^{-rT}N(d_{2})$$
