Monte Carlo Simulation

Where closed form solutions are not available, or the contract value is more path dependent, a Monte-Carlo simulation technique can be used instead. We use the underlying SDE to evaluate N paths of the asset, calculate our payoffs and then average across to get our option value.

The algorithm for using MC is simple:

  1. Partition the time interval [0,T] into m points, giving us m+1 time steps (including the start).
  2. Generate the underlying asset values using the related SDE under its measure (risk-neutral for the GBM)
  3. Calculate the payoffs at maturity and average them, i.e. $E^{Q}[H(T,S)]=\frac{1}{N} \sum^{N}_{i=1} H_{i}$
  4. Evaluate the option value by discounting back to today
  5. Calculate the standard error of your estimation

By the strong law of large numbers, we know that as N approaches $\infty$, the average payoff calculated above will aproach the expected value of the payoff at maturity with probability 1. The standard error can be calculated as follows:

$$Var^{Q}[H_{N}(T,S)] = Var^{Q}[\frac{1}{N}\sum{H_{j}}]$$

We can evaluate the standard error of the payoff using a sample variance estimator:

$$\upsilon^{2} = \frac{1}{N-1}\sum^{N}_{i=1} (H_{i} - H_{N})^{2}$$

The standard error can then be estimated by:

$$\varepsilon = \frac{\upsilon _{N}}{\sqrt{N}}$$

The standard error is the measure of variability in the estimator, i.e. what the error is in the sample variance.

Simulation of Stochastic Differential Equations

For a general SDE of the form $dX(t)=\mu (t,X(t))+\sigma (t,X(t))dW(t)$, its integrated form is of the form: $X(t_{i+1})=X(t_{i}) + \int _{t_{i}}^{t_{i+1}} \mu (t,X(t))dt + \int _{t_{i}}^{t_{i-1}} \sigma (t,X(t))dW(t)$. We can then approximate this function using a scheme such as the Eurler scheme, which approximates the integrals on the left side of the boundary as such:

$$\boxed{x_{i+1}=x_{i}+\mu(t_{i},x_{i})(t_{i+1}-t_{i})+\sigma(t_{i},x_{i})W(t_{i+1}-t_{i})}$$

We know $W(t_{i+1}-t_{i})$ is normally distributed with a mean 0 and variance $t_{i+1}-t_{i}$, so we can estimate it by $Z\sqrt{t_{i+1}-t_{i}}$, where $Z\sim N(0,1)$

Convergence

We are interested in the order of convergence of the computed average to the true value of the payoff (or whatever the simulation is for). We can seperate the order of convergence into two different orders: Convergence in the strong sense and convergence in the weak sense.

If we define $x_{m}$ as the approximation for X(T), and $\Delta t$ is the time step used in the discretization scheme, then the approximation $x_{m}$ converges in the strong sense to X(T) with order $\alpha > 0$ if: $E[|X(T)-x_{m}|] \leq c\Delta t^{\alpha}$ where $\alpha$ is the order of convergence. A higher value for this means reducing the size of $\Delta t$ actually reduces the error more significantly.

This is path-wise accuracy, meaning reducing the step size here will increase the accuracy of the path by reducing the error between the path value and the actual value. This is why in the strong convergence, we are looking at the expectation of the error size. This is important where the actual path itself matters more, for example Barrier options, Asian Options and lookbacks
