Brownian Motion

A Brownian Motion is a random variable W(t) defined on the probability space $(\Omega, F, P)$ which fulfils the following conditions:

  • 1. W(0)=0
  • 2. W(t) is a martingale i.e. E[W(t)$\vert$F(s)] = W(s)
  • 3. The increments of a Brownian Motion are normally distributed with a mean 0 and a variance equal to the difference in time.

The Brownian Motion also has quadratic variance at a rate of the change of time. Unlike smooth continious functions where you can zoom in enough to be able to describe the change as a linear change, a Brownian Motion can be zoomed into infinitely i.e. the function is not differentiable anywhere.

Markov Property

Let W(t) be a Brownian Motion on the probability space $(\Omega, F, P)$. Then W(t) is a Markov process. This means that the transition density of W(t) only depends on the value of W(s) for s $\leq$t, and the mean for the transition density will then be W(s), i.e. the only value that is relevant to the transition of W(t) is the value at the current time s, nothing before.

First Passage time and the Reflection Principle

Let W(t) be a Brownian motion with an associated filtration F on a probability space. Let T be a stopping time such that $(\omega :T(\omega )\leq t \forall T \in \Omega$. We are saying that T is a stopping time if and only if a sample or value $\omega$ is in the adapted filtration, basically if the outcome has already happened, such that the time it has occured is less than the current value of time.

Then, the first passage time principle describes the time $\tau _{m}$ as the first time the Brownian Motion associated with the filtration of the space crosses a real value m, such that:

$$\tau _{m} = inf(t \geq 0: W_{t}=m)$$

The optional sampling theorem states that for a martingale ${M_{t}:t\geq 0}$, with a bounded stopping time, $E[M_{t}]=M_{0}$. Any martingale stopped or frozen at some time t is still considered a martingale, therefore it must maintain the property of a martingale and the expected value of such martingale must be the value at time 0, or the last time its value was measured.

If we have a exponential martingale Z such that $Z(t) = e^{\sigma W(t) - \frac{1}{2}\sigma ^{2}t$, and we use the above described optional sampling theorem, we can show that the Laplace transform of the distribution of the first passage stopping time can be shown as:

$$E[e^{-\alpha \tau _{m}}] = e^{-|m| \sqrt{2\alpha}}$$

The idea behind the reflection principle is that if we have some level m, we know that there will be Brownian Motion paths that will cross that level and go above it, and there will be paths that will hit that level and return below it. Some may remain at that level. If we define some new level $\omega$ which is less than m, we are interested in the paths that drop below m to this level, and ones that go above. Interestingly, the reflection principle states that the probability of a path hitting m at a stopping time and dropping to below $\omega$ is the same as hitting m, and then travelling that same distance from m to $\omega$ above m i.e. $2m-\omega$. Essentially, the reflection principle states:

$$P{\tau _{m} \leq t: W(t) \leq \omega} = P{W(t) \geq 2m-\omega}$$

We are interested in deriving the cumulative distribution function i.e. $P(\tau _{m} \leq t)$. We do this by using the relfection principle, that if the stopping time is less than t, then there is an equal probability that currently the Brownian motion is above the associated stopping level, as it is below:

$$P(\tau _{m} \leq t) = P(\tau _{m} \leq t: W(t) \leq m), P(\tau _{m} \leq t) = P(\tau _{m} \leq t: W(t) \geq m)$$

If $W(t) \geq m$, then we know for sure that $\tau _{m} \leq t$, and so we can add the two probabilities together such that:

$$P(\tau _{m} \leq t) = P(\tau _{m} \leq t: W(t) \leq m) + P(W(t) \geq m)$$

$$P(\tau _{m} \leq t) = 2P(W(t) \geq m)$$

We that the Brownian motion is normally distributed with mean 0 and variance t, such that:

$$P(\tau _{m} \leq t) = 2 \int _{m}^{\infty} \frac{1}{\sqrt{2\pi t}} e^{-\frac{x^{2}}{2t}}dx$$

By using the substitution $y = \frac{x}{\sqrt{t}}$:

$$P(\tau _{m} \leq t) = \frac{2}{\sqrt{2\pi}} \int _{\frac{|m|}{\sqrt{t}}}^{\infty} e^{-\frac{y^{2}}{2}}dy$$

Distribution of max W(t)

As part of pricing exotic and barrier options, we are interested in seeing the distribution of the function M(t) = max W(t). We can use the reflection principle to see whether $M(t) \geq m$, where m is some level greater than 0. We can write:

$$P(M(t) \geq m, W(t) \leq \omega) = P(W(t) \geq 2m-\omega)$$

We can then write the joint distribution of W(t) and M(t) as:

$$f_{W(t), M(t)}(w,m) = \frac{2(2m-\omega )}{t\sqrt{2\pi t}}e^{-\frac{(2m-\omega )^{2}}{2t}}$$
