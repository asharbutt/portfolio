Proof of Brownian motion quadratic variation

We prove that the Quadratic Variation of a Brownian Motion is T by subdividing the interval [0,T] into n subintervals, and sampling the value of the Brownian Motion. We prove that the expected value of the quadratic variation is T with a variance close to 0.

We start by partinioning the interval via $\Pi_{n} = {t_{0},t_{1}, t_{2},...,t_{n}}$. We can then define the quadratic variation of this partition as:

$$Q_{\Pi} = \sum_{j=0}^{n-1} [W(t_{j+1}) - W(t_{j})]^{2}$$

We first show that the expected value is T. We take the expectation of both sides:

$$EQ_{\Pi} = E\sum_{j=0}^{n-1} [W(t_{j+1}) - W(t_{j})]^{2} = \sum_{j=0}^{n-1} E[W(t_{j+1}) - W(t_{j})]^{2}$$

The expected value of each increment is 0, and thus the variance of any increment is then given by: $Var(X) = E[(X-EX)^{2}] = E[X^{2}]$

Therefore, the expected value of the square of the increment is then the variance of the increment, which is equal to the change in time:

$$\sum_{j=0}^{n-1} E[W(t_{j+1}) - W(t_{j})]^{2} = \sum_{j=0}^{n-1} t_{j+1} - t{j} = T$$

We now prove the variance of the sum of the increment is 0. We start by taking the variance of the square of the increment:

$$Var([W(t_{j+1}) - W(t_{j})]^{2}) = E[([W(t_{j+1}) - W(t_{j})]^{2}) - E[[W(t_{j+1}) - W(t_{j})]^{2}]]^{2}$$

The expected value of the square of the increment, as shown before is:

$$E[([W(t_{j+1}) - W(t_{j})]^{2}) - E[[W(t_{j+1}) - W(t_{j})]^{2}]]^{2} = E[([W(t_{j+1}) - W(t_{j})]^{2}) - (t_{j+1} - t{j})]^{2} = E[[W(t_{j+1}) - W(t_{j})]^{4}] - 2(t_{j+1} - t{j})E[W(t_{j+1}) - W(t_{j})]^{2} + (t_{j+1} - t{j})^{2}$$

The first term is the 4th moment of the variable, which is the kurtosis of the distribution of the increment (given the increment has 0 mean you do not need to centralise the variable). This is given by $3\sigma^{4}$, which is $3t^{2}$. You therefore get:

$$3(t_{j+1} - t{j})^{2} - 3 (t_{j+1} - t{j}) + (t_{j+1} - t{j})^{2} = (t_{j+1} - t{j})^{2}$$

This means the variance of the sum then becomes:

$$Var(Q_{\Pi}) = \sum_{j=0}^{n-1} (t_{j+1} - t{j})^{2}$$

As the partition size approaches 0 and $n->\infty$, the limit of the variance approaches 0, meaning that the expected value of the sampled quadratic variance is T and the variance is 0.
