Moments

The kth moment of a variable X can be written as: $E[X^{k}]$. The first moment therefore is the expectation of the random variable. The kth moment only exists if the following expectation is finite: $E[|X^{k}|] < /infty$, and if the kth moment exists, then any jth moment will exist provided $j /leq k$. Therefore, if the second moment exists, then the mean and variance will exist, provided that the variance can be written as: $Var(X) = E(x^{2}) - [E(X)]^2$, basically the second moment minus the square of the first moment

Moment Generating Function

The moment generating function can be written as:

$$\psi (t) = E[e^{tX}]$$

If the random variable X is bounded, then the MFG will exist for all t. If not, then the MFG may only exist for some t. We know for certain the the MFG ALWAYS exists for t = 0, given this expectation always equals 1. We take the first derivative of the MFG w.r.t t, and show:

$$\frac{d}{dt}E[e^{tX}] = E[\frac{d}{dt}e^{tX}] = E[Xe^{tX}]$$

If we set t = 0, then the first derivative will give us the expected value of X, or the mean. We can show that the kth derivative of the MFG will actually lead to the kth moment of X when t = 0:

$$\frac{d^{k}}{dt^{k}}E[e^{tX}] = E[X^{k}e^{tX}] = E[X^{k}]$$
